# Kano Model（狩野模型）

## 概述

Kano Model 由日本学者狩野纪昭提出，用于对产品功能进行分类和优先级排序。核心理念：不是所有功能的"做好了"都能带来等量的用户满意度提升。

## 五类功能

1. **基本型（Must-be / Basic）**：用户认为理所当然的功能。没有它用户会极度不满，但做好了用户也不会更满意。例：电商 App 的支付功能、社交 App 的注册功能。

2. **期望型（Performance / One-dimensional）**：用户期望的功能，做的越好用户越满意，做的越差用户越不满意。满意度与功能完成度呈线性关系。例：App 的加载速度、客服响应时间。

3. **兴奋型（Attractiveness / Delighters）**：用户没有想到的功能，没有它用户不会不满，但有了会大大提升满意度。例：Google Docs 的实时协作、AirPods 的自动连接。

4. **无差异型（Indifferent）**：有和没有用户都不太在意。这类功能是浪费资源的信号。

5. **反向型（Reverse）**：做了反而让用户不满的功能。例：强制弹窗广告。

## 时间衰减效应

兴奋型功能会随时间退化为期望型，最终退化为基本型。今天的"wow"是明天的"table stakes"。

触屏智能手机刚出现时，多点触控是兴奋型功能。现在它是基本型功能——没有触屏的手机会被认为是坏的。

## 产品策略应用

- **MVP 阶段**：确保基本型完整 + 1-2 个核心期望型 + 1 个兴奋型
- **成长期**：持续提升期望型功能的竞争力 + 探索新的兴奋型
- **成熟期**：监控兴奋型退化，避免在无差异型功能上投入

## 如何做 Kano 问卷

对每个功能问两个问题：
1. 如果这个功能存在，你的感受是？（正向问题）
2. 如果这个功能不存在，你的感受是？（反向问题）

每个问题用 5 级量表：我喜欢 / 理所当然 / 无所谓 / 可以忍受 / 我不喜欢

通过交叉分析两个问题的答案，将功能归入 Kano 五类。
